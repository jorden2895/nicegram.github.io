# What features does Nicegram add?

Nicegram combines Telegram-compatible messaging with its own account, privacy,
productivity, AI, and wallet surfaces. This index separates generally available
features from beta, limited-rollout, and source-only work.

## Accounts and privacy

| Feature | What it does | Status |
|---|---|---|
| Expanded accounts | Keeps more Telegram accounts in one client | Available on mobile |
| Account backup/import/export | Transfers supported account sessions between client setups | Platform-dependent |
| Double Bottom | Reveals a separate hidden account surface through an alternate access action | Available on mobile |
| Hidden chats | Removes selected chats from the normal chat list | Available on mobile |
| Immediate auto-lock | Shortens the time before the app lock engages | Platform-dependent |
| Hide phone number | Adds a client control around phone-number visibility | Platform-dependent |

Read [Privacy controls](privacy.md).

## Messaging, language, and media

| Feature | What it does | Status |
|---|---|---|
| Quick replies | Reuses saved response templates | Available on mobile |
| Anonymous forwarding / forward as copy | Sends content without the original forwarding attribution where supported | Platform-dependent |
| Direct save / private reply | Adds shortcuts around saved messages and group replies | Platform-dependent |
| Bulk selection | Selects more messages for a shared action | Platform-dependent |
| Incoming and outgoing translation | Translates received text or text before sending | Available on mobile |
| Speech-to-text | Produces a transcript from supported audio | Platform/plan-dependent |
| Existing video as video message | Converts a compatible local video into a round message | Available on mobile |
| Rear-camera preference | Starts supported video capture with the rear camera | Platform-dependent |
| Call recording | Records supported calls and saves the result through the app flow | iOS; consent required |
| Advanced cache/download controls | Gives additional control over local media handling | Platform-dependent |

Read [Messaging tools](messaging.md),
[Translation and speech-to-text](translation-and-voice.md), and
[Media and call tools](media-and-calls.md).

## Profiles and organization

| Feature | What it does | Status |
|---|---|---|
| Show Telegram ID | Displays an account or peer identifier in supported profile surfaces | Available on mobile |
| Registration date estimate | Shows an estimated Telegram-account registration period | Available on mobile; estimate |
| Clickable bio links | Makes supported links in profile bios directly actionable | Platform-dependent |
| Remember last folder | Returns to the previously selected chat folder | Platform-dependent |
| Keyword folders | Organizes or surfaces chats around configured keywords | Limited rollout |
| Hide unused tabs | Removes selected Nicegram navigation items | Platform-dependent |

Read [Profiles, folders, and interface](profiles-and-folders.md).

## AI, wallet, plans, and programs

| Feature | What it does | Status |
|---|---|---|
| AI Assistant | Answers prompts and assists with writing or understanding content | Beta / plan-dependent |
| AI chat shortcuts | Summarizes, explains, rewrites, or generates content from supported contexts | Beta / limited rollout |
| Image generation and math assistance | Produces images or helps work through a problem | Beta / provider-dependent |
| Wallet and dApps | Creates or connects wallet surfaces and opens supported decentralized apps | Store-listed; rollout varies |
| Gems / AI balance | Represents eligible usage credit for supported paid actions | Account/plan-dependent |
| Referral program | Gives an eligible user a referral route and tracks qualified results | Region/terms-dependent |
| AI Agent Marketplace | Discovers and uses eligible AI agents | Beta |
| Escrow / HyperLancer | Supports eligible marketplace work and protected payment flows | Beta |
| God’s Eye / Spy on Friends | Contact-activity insight surfaces listed by Nicegram | Limited rollout; results are not guaranteed |

Read [Nicegram AI](ai.md), [Wallet and dApps](wallet.md),
[Plans, Gems, and referrals](plans-and-rewards.md), and
[Beta and limited-rollout features](beta.md).

## What is not listed as a Nicegram feature

Normal Telegram chats, channels, calls, Secret Chats, Stories, bots, and Telegram
Business features remain Telegram capabilities when Nicegram does not add a
distinct workflow. Their behavior follows Telegram and can change with upstream
client updates.
